Norric Intelligence MCP · v2.0.0

Swedish intelligence API
for AI agents.

25 functions are registered across insolvency risk, municipal procurement, company lifecycle, website leads, and BRF intelligence. Some are live, some partial, and some are inactive until their pipelines are connected. Status is shown per tool below.

MCP server: https://mcp.norric.io/mcp
Transport: Streamable HTTP · FastMCP 3.2.3 · Protocol 2024-11-05
Functions: 25 registered; availability varies by function and tier
Coverage: 17,916 companies tracked (live health, 14 September 2026) · 33,710 scored BRFs

Quick start

Connect to the Norric MCP server in under 60 seconds.

Step 1 — Discover without an account

Connect directly to https://mcp.norric.io/mcp. Initialize, keep the returned mcp-session-id, then call tools/list. No API key is needed for discovery, status, freshness, or an x402-gated call.

Step 2 — Claude Code (recommended)

claude mcp add norric https://mcp.norric.io/mcp \
  --header "Authorization: Bearer YOUR_API_KEY"

Then use any tool directly in Claude Code:

# Score a Swedish company for insolvency risk
mcp__norric__kreditvakt_score_company_v1(orgnr="556012-3456")

# Get this week's procurement call list
mcp__norric__signal_weekly_call_list_v1(vertikal="aldreomsorg", limit=10)

# Check pipeline freshness before acting
mcp__norric__norric_data_freshness_v1()

Step 3 — Muse Code

Add Norric to your Muse Code settings file under mcp_servers. The server is optional so a temporary Norric outage does not stop the whole Muse run.

{
  "mcp_servers": {
    "norric": {
      "transport": "streamable_http",
      "url": "https://mcp.norric.io/mcp",
      "enabled": true,
      "mode": "optional"
    }
  }
}

Restart Muse Code after saving, ask it to list Norric tools, then call free status/freshness. Paid calls require an x402-capable wallet client; no Norric account is required.

Step 4 — Claude Desktop

Edit ~/Library/Application Support/Claude/claude_desktop_config.json:

{
  "mcpServers": {
    "norric": {
      "url": "https://mcp.norric.io/mcp",
      "transport": "streamable-http",
      "headers": { "Authorization": "Bearer YOUR_API_KEY" }
    }
  }
}

Step 5 — Cursor or Windsurf

Edit .cursor/mcp.json:

{
  "mcpServers": {
    "norric": {
      "url": "https://mcp.norric.io/mcp",
      "headers": { "Authorization": "Bearer YOUR_API_KEY" }
    }
  }
}

Authentication

Agents can initialize and discover tools without an account. Free calls are norric_status_v1 and norric_data_freshness_v1. A payment-gated tool challenges an unpaid call and accepts a signed x402 retry. Other anonymous tool calls return 403. Existing API-key clients may still use Authorization: Bearer or X-Norric-Key.

Authorization: Bearer nrk_your_key_here

Get a key: norric.io/api-keys

Key tiers

TierAccessQuota
Agent freeDiscovery, norric_status_v1, norric_data_freshness_v1No account; abuse controls apply
StandardAll registered toolsNo monthly cap in current backend policy
ComplianceAll registered tools + audit-log accessNo monthly cap in current backend policy

Missing or invalid key returns:

{
  "error": "Invalid API key. Get yours at norric.io/api-keys"
}
Never expose your API key in client-side code, logs, or user-visible output. Keys are associated with your account and rate limits are enforced per key.

Connect your agent

Claude Code and Claude Desktop handle the MCP handshake automatically. For direct HTTP calls, a two-step session initialization is required.

MCP server: https://mcp.norric.io/mcp
Transport: Streamable HTTP (FastMCP 3.2.3)
Protocol version: 2024-11-05

Direct curl — two-step handshake

# Step 1 — Initialize and capture session ID
SESSION=$(curl -si https://mcp.norric.io/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{
    "protocolVersion":"2024-11-05",
    "capabilities":{},
    "clientInfo":{"name":"curl","version":"1.0"}
  }}' \
  | grep -i "mcp-session-id" | awk '{print $2}' | tr -d '\r')

# Step 2 — Call a tool
curl -s https://mcp.norric.io/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "mcp-session-id: $SESSION" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{
    "name":"kreditvakt_score_company_v1",
    "arguments":{"orgnr":"556012-3456"}
  }}'

Health check

curl https://mcp.norric.io/health
# → response includes "status", "mcp_tools", "products", and pipeline freshness

Tools reference

25 functions are registered. Parameters vary by tool: company tools use orgnr or a search string, SIGNAL uses kommunkod and vertikal, Sigvik uses BRF IDs, and SiteLoop uses city or lead fields. Check each signature in your MCP client.

Kreditvakt — Insolvency scoring live

17,916 companies are currently tracked according to live health. Companies are scored on a 0–20 scale from four independent signal sources: Skatteverket restanslängd, Kronofogden betalningsförelägganden, Bolagsverket ärenden (pre-registration leading indicator), and Bolagsverket konkursregister. Early-warning tier includes F-skatt registration, building permits, and Bolagsverket ownership velocity sensors.

ToolDescriptionKey params
kreditvakt_score_company_v1 Insolvency risk score on a 0–20 scale (20 = severe). Accepts orgnr only; use norric_search_v1 to resolve a name first. orgnr
kreditvakt_batch_score_v1 Score up to 500 organisation numbers in one call. Returns a portfolio risk summary. orgnrs[]
kreditvakt_debt_signals_v1 Skatteverket and Kronofogden debt signals only. orgnr
kreditvakt_bankruptcy_status_v1 Bolagsverket konkurs status and pending ärenden. orgnr

Response envelopes

Most product tools return {data, metadata, signals, warnings}. The two provenance helpers use the alternate NorricResponse shape. Authentication failures are bare {error} objects with HTTP 401.

{
  "data": { /* tool-specific payload */ },
  "metadata": {
    "response_id": "nrsp_abc123",
    "tool": "kreditvakt_score_company_v1",
    "source": ["skatteverket", "bolagsverket"],
    "fetched_at": "2026-09-14T06:56:00Z",
    "confidence": 0.87,
    "cache_ttl_seconds": 3600,
    "is_cached": false
  },
  "signals": [],
  "warnings": []
}

Field reference

FieldTypeDescription
dataobjectTool-specific payload.
metadataobjectTool, sources, fetch time, confidence, TTL, and cache state.
signalsarrayEvidence used by the tool; empty when not applicable.
warningsarrayFreshness, availability, or pipeline warnings.
Client guidance: Call norric_data_freshness_v1 before any consequential workflow (credit approval, sales outreach, procurement bid). If any source is older than 7 days, note this in your output.

Error codes

CodeMeaningWhat to do
401 Missing or invalid API key Get key at norric.io/api-keys
404 Company or entity not found Verify orgnr format: XXXXXX-XXXX (10 digits)
429 Rate limit exceeded Wait 60 seconds, retry with exponential backoff
503 Data source temporarily unavailable Retry after 5 minutes

Authentication failures use a bare error object:

{ "error": "Invalid API key. Get yours at norric.io/api-keys" }
Client retry guidance — 429: Wait 60 seconds, retry once. If you receive a second 429 in the same session, stop and inform the user. Do not loop.

Pricing

Agent prices are exact per call. Discovery, status, and freshness are free. The current review stack wires kreditvakt_score_company_v1 at 2,000 atomic test USDC ($0.002 nominal). Network: Base Sepolia testnet (eip155:84532); mainnet is blocked.

Wallet payment flow

  1. Initialize anonymously and call tools/list.
  2. Call kreditvakt_score_company_v1 without payment to receive its x402 v2 exact challenge.
  3. Sign the accepted requirement with the agent wallet.
  4. Retry the same call with the payload in params._meta["x402/payment"].
  5. Read settlement from result._meta["x402/payment-response"].
Facilitator: https://x402-facilitator-production-5948.up.railway.app/
