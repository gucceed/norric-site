The rail · what Norric is becoming
📇
Official registers only
The country connectors use official national company registers: Bolagsverket in Sweden, CVR in Denmark, Brønnøysund in Norway and PRH in Finland. Sweden is queryable; check freshness before relying on the other countries. Source and freshness are exposed to callers.
💳
Per-call, paid by the caller
Agents can discover the tools for free. Paid Swedish verify calls are quoted at $0.002 nominal test USDC; changes feed calls at $0.02. Each is a separate x402 payment on Base Sepolia testnet. Neither mainnet settlement nor a recurring subscription is live.
🔌
Zero onboarding
Machine-readable discovery through the x402 manifest, OpenAPI, llms.txt and free tools/list. An agent can discover the server without an account or API key. Wallet-paid calls need an x402-capable client and test USDC.
🇪🇺
EU-resident data processing
Production database in Stockholm; application compute and payment facilitator in Amsterdam. No personal data is ingested. For EU-only handling, a snapshot option is available. The public website currently uses Vercel CDN, so this claim covers the data-processing rail rather than every website request.
🧭
Machine trust by default
Freshness is queryable, coverage is stated per tool, and failure is honest: found=false instead of a guess. That is what gets an agent to call twice.
🏛️
Built for the operator too
The operator can inspect source provenance, status and freshness before using a response. Data loads are staged country by country, and warning-bearing results should not be treated as live intelligence.
Thesis
Norric is becoming the rail agents use to check European companies. The Kreditvakt and Sigvik public sites are paused while their claims remain unverified. SIGNAL is still being built; its MCP tools are registered but its live-data activation is not complete.

The bet is simple: agents do not read marketing, they read manifests, and their eval loops punish anything that guesses. So the rail earns trust the machine way - official registers only, freshness you can query, honest failures, provenance on every response. Snapshots do not compound; history and subscriptions do. Sweden is queryable now. Denmark, Norway and Finland have paid routes in production, while their national data coverage must be checked for freshness. Estonia and France remain gated until their first loads.
